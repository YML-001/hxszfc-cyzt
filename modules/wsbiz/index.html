九条主业务链演示路径

按顺序点，能看到状态跨页流转
收件到办结
事项目录配置 → 身份核验 → 五步收件向导 → 材料核验 → 出回执 → 待办中心自动出任务 → 签收领办 → 审批办理 → 出件办结 → 台账与评价。
补正闭环
一次性补正通知 → 材料补正页倒计时 → 申请人线上补交 → 经办人复核通过 → 办件回到办理中；逾期则终止或退件。
更正撤销
已办结件 → 更正撤销申请 → 生成 gzbs 标识的新办件 → 按原审批链复核 → 业务库、档案、上级报送三处同步。
材料免提交
材料库定义 → 免提交清单发布 → 收件时电子证照调用、历史材料复用或数据共享代替 → 材料清单自动置为免提交。
预约到号
号源配置 → 网上预约（满额拦截）→ 取号进队 → 叫号推进（预约号优先）→ 到场率与失约率变化。
帮办预审
材料网上预审通过 → 帮办代办受理 → 收件方式标记为帮办代办 → 一次办结；预审不通过自动生成补正。
差评整改
办结后评价 → 差评自动生成核实任务进待办中心 → 核实结果与整改措施 → 闭环并更新满意度与效能指标。
催办督办
临期或超期 → 催办生成催办任务，超期自动升级为督办 → 推送科室负责人 → 消息中心与顶栏红点联动。
一件事并件
合并收件勾选关联事项 → 生成 1 主件 + N 子件 → 主件未办结前子件办结被拦截。
