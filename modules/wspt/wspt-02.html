应用是权限链路的终点：用户 → 角色 → 菜单/按钮 → 权限资源 → 应用。 停用应用后，该应用下所有菜单即时从各角色菜单树收回，但历史操作日志保留可查。

ancestors 祖级路径是「本部门及以下」数据范围的判定基础。 落地要求：子树查询使用 ancestors 路径 LIKE 匹配（当前部门 ancestors ＋ 当前部门 id 前缀）或 id 等于当前部门， 禁止递归查询。部门层级变动时必须同步维护 ancestors，否则该部门子树的数据范围会算错。

岗位与角色是两条独立的线：角色决定能看什么、能点什么（权限），岗位决定在流程中被谁指派（审批人配置可按岗位取人）。 停用岗位后，已按该岗位配置的流程节点须改配审批人，否则实例会找不到办理人。
