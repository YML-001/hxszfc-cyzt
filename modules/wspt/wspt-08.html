流转条件基于表单字段写条件表达式，多条出线按优先级依次判定，命中即走、不再往下判。 每个条件网关必须有一条兜底出线（条件恒真），否则可能出现无出线可走、实例卡死。

表达式引用的字段必须在绑定表单中存在；表单升版本删字段时， 设计器会提示哪些条件表达式会失效，未处理不得发布。

节点级字段权限三档：可写、只读、隐藏（字典 wf_field_perm）。 同一张表单在不同节点呈现不同形态——例如「申请金额」在发起节点可写、在审核节点只读、 「内部审核意见」对企业端节点隐藏。隐藏是后端不下发该字段，不是前端 CSS 藏起来。

试跑推演 · 重点资金使用审批 v2
路径 1 · 金额 ≤ 500 万且非高危
开始 → 受理 → 初审 → 审核 → 抄送分管领导 → 结束。可达 end，4 个审批节点均可取到人。
路径 2 · 金额 > 500 万或高危项目
开始 → 受理 → 初审 → 复核 → 审核 → 抄送分管领导 → 结束。可达 end。
路径 3 · 任一审批节点退回
退回至受理节点，补正后重新流转。不产生死循环（退回次数上限 3 次）。
兜底出线检查
条件网关「金额分档」有 3 条出线，第 3 条为兜底（条件恒真）。
