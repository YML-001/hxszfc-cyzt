十条业务闭环链跨页面真实联动，可逐条走查
链条 1挂牌 → 核验发码 → 上架检索 → 举报核实 → 下架并扣信用分 → 红黑榜位次变化
链条 2选事项 → 看指南 → 在线申报 → 我的办件 → 待补正提醒 → 补交 → 办结出证 → 待评价
链条 3填报未提交存草稿 → 个人中心显示 → 续办带出已填内容 → 提交后草稿销毁
链条 4查询本人 → 二次核验 → 留痕 → 脱敏结果 → 打印带验真码证明 → 验真可查
链条 5查他人 → 无授权拦截 → 发起授权 → 权利人同意 → 放行；撤回后立即失效
链条 6智能问答 → 未解决转人工 → 满意度评价 → 低分回流知识缺口清单
链条 7企业入网通过 → 进名录公示 → 人员登记 → 服务评价累积 → 信用分与榜单变化
链条 8销控表选房 → 认购登记 → 房号变色 → 缴款到账 → 交付节点 → 退房进公示
链条 9公示页订阅 → 后台发布新公示 → 我的消息收到推送 → 首页提醒条 +1
链条 10后台改浏览范围 / 脱敏口径 / 事项目录 → 前台拦截、字段遮蔽、事项列表随之变化
技术说明：纯静态 HTML + CSS + 原生 JavaScript，无框架、无构建，双击即可打开。 共享设计系统 assets/css/portal.css，页面专属样式写在各页 <style> 内。 状态引擎 assets/js/portal-flow.js 负责 6 个状态机与全部闭环动作，数据存 localStorage（wsmh.flow.v1）， file:// 协议下自动退化为内存。图片来自 Unsplash，图标使用 Font Awesome 6.5.0。
