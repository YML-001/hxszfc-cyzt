授权规则：非本人查询他人房产信息必须取得权利人在线授权，授权范围、期限与撤回情况全程可查。 权利人同意后申请人才能查询，权利人撤回后立即失效。全部授权与查询行为都记入留痕，供事后审计与异常查询排查。

系统记录每一次查询的查询人、查询对象、查询类型、查询用途、查询时间与查询渠道，供事后审计与异常查询排查。 同一对象 24 小时内被查询 3 次以上会标记为异常并提示核查。

查询留痕台账

银行、法院、公证等机构的批量查询申请须经审核后执行，结果按次限量发放并留痕。 机构须承诺查询结果仅用于申请事由，不得留存、转发或用于其他用途。

批量查询办理流程

1. 提交申请
机构在线提交查询清单与查询事由
机构办理
2. 资格审核
核验机构资格、查询事由与法律依据
档案管理科
3. 按次发放
审核通过后按申请笔数限量发放查询结果
系统自动
4. 全程留痕
逐笔记录查询对象与发放时间，可追溯
系统自动
