# 统一服务门户（wsmh）功能点闭环清单 v1.0

> 依据《柳州市数智房产交易一体化平台功能板块梳理v1.9》「统一服务门户（一网通办）」功能域全部 184 个二级功能点，
> 与《柳州市数智房产交易一体化平台菜单梳理v1.0》wsmh 子系统 8 个一级栏目 / 35 个二级模块。
> 本清单是原型开发依据，也是验收依据。每个可点元素在 HTML 中带 `data-fp="wsmh-XX-NN"` 标记，`checklist.html` 逐条可验。

**闭环类型说明**

- 操作型：有明确的触发元素，点击后写入状态、跨页面可见结果。
- 展示型：闭环体现在页面上有对应展示元素与口径标注，验收方式为「在 XX 页可见 XX」。
- 配置型：在后台改配置，前台展示或权限随之变化。

**页面路径约定**：`web/` 公众站、`person/` 个人中心、`company/` 企业机构工作台、`admin/` 门户配置后台、`kiosk/` 自助终端。
