首页门户运营后台门户框架配置
门户框架配置（wsmh-34）决定门户怎么分设、首页按角色怎么渲染、内容发到哪些端、子平台怎么免登跳转， 以及未登录能看到什么。本页每一项配置保存后前台立即生效，每个配置项都给出了受影响的前台页面与验证入口。
门户分设配置 首页角色渲染 多端内容一源发布 单点跳转免登 未登录浏览范围与实名门槛

门户分设配置

wsmh-34-01
预览服务门户
平台按使用对象分设统一工作门户与统一服务门户两个门户： 同一域名、同一登录体系、同一内容源，用户登录后按角色自动进入对应门户； 内部业务人员进工作门户办业务，群众与企业进服务门户办事，两侧看到的事项目录、公示内容与房源数据完全同源。
影响前台：停用后该门户入口不再对外提供，服务门户首页顶部与政务条的门户入口随之隐藏； 两个门户至少保留一个启用。 去前台验证

首页角色渲染规则

wsmh-34-02
规则说明：同一个首页地址（web/home.html）按登录身份渲染不同内容。 未登录只渲染公开浏览部分；登录后在首屏叠加待办、待缴款、待补正、待签约、待评价五类提醒， 并把金刚区与常用服务换成该角色的办事情形；门户运营角色额外在政务条出现「运营后台」入口。

切换身份预览

直接以该身份打开前台首页，查看渲染差异
影响前台：切换身份后打开 web/home.html，首屏提醒条、办事情形金刚区与政务条右侧入口随角色变化； 身份记录在会话中，返回后台时保持一致。

多端内容一源发布

wsmh-34-03
去新建稿件
栏目内容一处维护、多端展示：稿件、办事指南与公示信息只在后台维护一次， 按下面启用的渠道自动分发到 PC 门户、手机端 H5、微信小程序、政务自助终端与大厅大屏， 各端内容与更新时间保持一致，不做二次录入。
发稿时可逐篇勾选发布渠道；此处停用的渠道在发稿页不再出现，已发布稿件在该端停止展示。
查看稿件已发布渠道
影响前台：栏目内容管理 → 新建稿件的「发布渠道」多选项与稿件列表的渠道标签随本配置变化。 去发稿页验证

业务子平台单点跳转免登

wsmh-34-04
从统一门户跳转各业务子平台免二次登录：门户以 Token 透传方式将当前会话与角色权限传递给子平台， 子平台校验 Token 后直接建立同一会话，会话有效期、实名等级与操作权限与门户完全一致； 会话超时或退出登录后，子平台会话同步失效。
Token 透传采用一次性票据，有效期 60 秒，仅允许在本平台域名内使用；跳转与回跳全过程记录审计日志。
影响前台：本清单与门户站点管理 → 业务子平台入口同源， 子平台启用状态决定首页「业务子平台入口」区块是否展示该入口。 去入口配置

未登录浏览范围

wsmh-34-06　配置即时生效
开关开启表示未登录用户可以直接使用；关闭表示该操作需要登录， 未登录用户点击时会被拦截并引导到登录页，拦截提示中会标注本配置项的位置。 按对外服务口径，房源列表与详情、信息公示、办事指南默认开放浏览， 预约与咨询、信息查询、在线办理、服务评价默认需登录实名。

会话超时设置

wsmh-34-06
超时后需重新登录；未提交的申报内容会自动存为草稿，可在个人中心继续办理。
前台登录页与个人中心「账号安全」处展示同一取值。
影响前台：web/login.html 的安全提示与 person/index.html 账号安全中的「会话超时」数值随之变化。 去登录页验证

实名等级门槛

wsmh-34-06　按实名等级控制可办范围
实名等级由统一身份认证返回：未实名仅可浏览；个人实名（人脸或银行卡四要素核验）可办个人自助情形； 企业实名（法人认证 + 经办人授权）可办企业类事项。跨等级操作一律拦截并提示升级方式。
将当前身份切换为未登录，打开二手房详情页后点击「预约看房」，即可看到拦截与登录引导。
