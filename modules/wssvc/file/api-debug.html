这个调试台主要给两拨人用。 一是新应用接入时的自测——照着这里跑通上传、拿外链、预览三步，接入基本就成了； 二是出问题时的复现——调用日志里点「在调试台重放」， 把当时的参数原样带过来再发一次，看是偶发还是必现。 调试产生的文件落在联调桶，不污染生产数据。
