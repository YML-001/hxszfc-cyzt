接口调试台 · 政银直连
应用配置 调用日志
这个调试台有两个用途。 一是出向接口的联调：选银行、选接口、填参数、发起真实调用、看请求响应报文—— 新接入一家行或对方改了报文时用它验。 二是入向接口的模拟触发：缴存回传、划转回传、放款解付通知这些是银行推给平台的， 平时没法主动测，这里用模拟报文触发一次，看平台的匹配与回写对不对。 模拟回传也是桂林银行故障期间补录漏推流水的正式手段。
